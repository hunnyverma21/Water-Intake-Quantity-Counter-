# Water Intake Quantity Counter

A simple Python command-line project to track how much water you drink during the day.

## Features
- Set a daily water-intake goal in millilitres (ml).
- Add the amount of water consumed.
- View total intake in ml and litres.
- See the percentage of your goal completed and the amount remaining.
- Change your daily goal.
- Input validation for invalid or non-positive values.

## Requirements
- Python 3.x
- No external libraries are required.

## How to Run
1. Download or extract this project folder.
2. Open a terminal or command prompt in the project folder.
3. Run:

   ```bash
   python main.py
   ```

## Example
If your goal is `2000 ml` and you add `500 ml` four times, your total intake will be `2000 ml` (2 litres), and your goal will be reached.

## Project Files
- `main.py` — application code.
- `problem statement.txt` — project problem statement.

## Note
This project is a basic tracker. It does not save records after the program is closed, and its default goal is user-defined rather than medical advice.
